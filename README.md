# AI Diet & Meal Planner

A multi-agent meal planner. Tell it what ingredients you have and what diet you follow, by typing or speaking, and it suggests recipes that fit, using only what you have.

Built as a Hyperskill project for a Maven Agentic AI Engineering course, then extended with a chat interface.

## How it works

Each agent is a Python class that sends one structured prompt to an LLM (via Groq) and validates the JSON it gets back with Pydantic.

1. **Parser agent:** turns a typed or spoken sentence into an ingredient list and a diet.
2. **Inventory agent:** removes blank or unusable ingredients.
3. **Diet agent:** keeps the ingredients that fit the diet and suggests five recipe ideas.
4. **Planner agent:** turns a recipe idea into a full recipe, using only the available ingredients plus basic pantry staples.

The **manager agent** runs the inventory and diet agents in order. Speech is transcribed with Groq's Whisper model.

## Two ways to use it

- **Streamlit chat app** (`streamlit_app.py`): a chat page with a microphone button.
- **FastAPI service** (`main.py`): JSON endpoints `/inventory`, `/diet`, `/ask`, `/plan` and `/recommend`, with logging and a Dockerfile.

## Run it locally

1. Get a Groq API key at https://console.groq.com.
2. Create a `.env` file in this folder:
```
   GROQ_API_KEY=your-key-here
```
3. Install the packages:
```
   pip install -r requirements.txt
```
4. Start the chat app:
```
   streamlit run streamlit_app.py
```
   Or the API:
```
   uvicorn main:app --reload
```
   Then open http://localhost:8000/docs.

## Run the API with Docker

```
docker build -t ai-diet-planner .
docker run --env-file .env -p 8000:8000 ai-diet-planner
```

## Note

Recipes are generated by an LLM. For medical diets, check suggestions against guidance from your care team.
